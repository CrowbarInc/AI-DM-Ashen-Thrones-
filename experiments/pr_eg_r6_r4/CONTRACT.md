# PR-EG-R6-R4 frozen evaluation contract

Labels and host-authored facts are written before provider exposure. Development,
validation and holdout partitions are byte-hashed before any call. No tuning or
label edits after freeze. All runs verify corpus and adapter hashes. A/B/C see the
same gold question meanings, NPC knowledge and eligible prose records. Only B/C
consult authored semantic facts. This is a material input/authoring difference,
measured and reported, not evidence that B solves unstructured prose.

A preserves the production prompt, schema and `coverage` implementation unchanged.
Its primary adapter evaluates each gold subquestion using the production kernel.
Shared aggregation retains multiple bindings and calls conflict PARTIAL; production
currently calls multiple direct sources clarification. Primary results are kernel
results, not production /api/chat qualification. Secondary results preserve a native
production authorization result separately from the same-kernel replay.

B performs open predicate/named role unification. C proposes witnessed source
propositions and answer spans. A quote alone never certifies a semantic role: C
requires independently authored fact agreement, or rejects as unverified. This
creates an explicit manual authoring burden. Restricted/unknown/foreign/invalid
provenance records never enter any provider payload. Final disclosure uses the
unchanged host authorization function after every positive correspondence.

DIRECT supplies all requested arguments without strengthening qualifiers. PARTIAL
supplies some information, or only an unidentified participant, rumor, or unresolved
conflicting candidates. RELATED_NONANSWER concerns the same subject without
supplying an eligible requested relationship/role. UNKNOWN has no eligible
support. CLARIFICATION_REQUIRED means the question itself is ambiguous. RESTRICTED
means known relevant host evidence is denied; the refusal contains no source text.
Rumor/conflict bindings are candidates, never canonical truth.

Score class, relevance, sufficiency, exact named bindings, roles and qualifiers,
source eligibility, false acceptance and false rejection independently. Missing
bindings are not correct role preservation. A fail-closed UNKNOWN is not an answer.
All denominators and strata are recorded. Forbidden claims are prohibited as
answer bindings, not as a mention inside a qualified host source quotation.

Decision: no forced winner. A/B requires complete real provider evidence, frozen
holdout results, zero tested authorization escapes, materially better supported
answer recovery on validation and holdout, no increased false acceptance, and a
credible authoring burden. Repeated templates are correlated; report paired exact
counts, Wilson class intervals and no population-level causal claims. No migration.

One attempt per case. No automatic repair/retry. Record transport/schema failures.
Prompts: A = current production source hash; C = engine.VERSION/C_PROMPT. Both use
the configured model, temperature 0, max output 1800. B makes zero provider calls.
Secondary uses fresh unhinted production interpretations on one held-out variant
of each family, then reruns all kernels; C receives that actual interpretation.

Security mutations include forged/cross-context IDs, reversed roles, fabricated
spans, unsupported answer values, temporal/epistemic strengthening and history
laundering. They supplement, never replace, real provider evidence.

No production source, persistent game data, holdout predecessor, feature default,
canonical fact, clue discovery, history or API response is edited by this cycle.
Production file/data hashes must agree at closeout. This does not qualify final
sealing, API/history agreement or durable referents anew; their code is unchanged.
