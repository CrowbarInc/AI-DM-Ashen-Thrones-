# PR-DI Recommendation

PR-DI decision: **A - EVIDENCE SUPPORTS TARGETED EXPERIMENT**.

The evidence does not support replacing Candidate A with B or C. It does support a narrower experiment: deterministic execution remains the authority spine, while AI is tested for targeted clarification and compound/unsupported-intent interpretation before any state mutation.

## Why Not Current Pipeline Alone

A is cheapest and safest but misses the cases this cycle cares about most: ambiguous pronouns, compound actions, explicit canon declarations, and mechanical override requests. It often preserves state only because the engine does not execute the requested mutation, not because it returns a useful explanation.

## Why Not Candidate B As A Replacement

B produced the most consistently useful interpretations: six of six valid intent reads by PR-DI scoring, including useful clarification on ambiguity and mechanical/authority pressure. But half its live plans failed validation, and two failures involved unauthorized or unsupported mutation proposals. B is evidence for targeted interpretation/clarification, not direct execution authority.

## Why Not Candidate C As A Replacement

C obeyed the tool boundary and made no invalid tool-name calls, but PR-DH live transcripts show no successful action execution in these six scenarios. It spent the most tokens and included redundant/permission-denied loops. C's best evidence is for narrow information/rules probes, not broad tool-agent execution.

## Recommended Next Step

Run a targeted, no-production-save experiment: deterministic first, then a constrained AI clarification/planning call only when deterministic output has unresolved references, unsupported mechanics, authority-declaration language, or compound-action markers. Measure whether it improves player-useful clarification and compound decomposition without allowing model-authored state mutation.
