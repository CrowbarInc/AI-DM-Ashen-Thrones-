# PR-CT Deduplication Contract

Eligible removal was limited to instruction strings in provider payload instructions that are present verbatim in the selected system prompt. The system prompt keeps the higher-priority canonical copy; payload policy objects, resolver decisions, visibility contracts, CTIR-derived projections, validators, persistence, and audit logs are not removed.

Removed category: exact system-owned duplicate instruction. Semantic near-duplicates, retry feedback, provenance-bearing facts, visibility/certainty-bearing claims, and validator inputs remain in place.
