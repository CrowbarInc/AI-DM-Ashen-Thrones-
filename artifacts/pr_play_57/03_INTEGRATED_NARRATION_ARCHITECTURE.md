# Architecture

Authoritative resolver → existing detached hook input → existing anchored authority → integrated outcome projection → one expression-adapter request → legacy validator + unchanged PR55 + coverage → quarantine record only. No integrated candidate is assigned to gm_output or campaign state.

Opt in with ASHEN_QUARANTINE_INVESTIGATION_NARRATION=1 and ASHEN_QUARANTINE_NARRATION_MODE=integrated. Real requests additionally require ASHEN_QUARANTINE_NARRATION_LIVE=1 and durable provider accounting. Omitting mode preserves the prelude mode; omitting the gate preserves deterministic behavior. Output cap remains the existing 80 tokens, below the requested 700 ceiling. Prelude ceilings remain 6/1000/10000; integrated ceilings are 8/700/12000. No automatic retry.

Side-effectful investigations are rejected before the legacy detacher can drop effect fields. Unsupported effects are a documented limitation, not a second authority representation. All failures retain the existing API deterministic response. Implementation.diff is incremental against entry source, including previously untracked files.
