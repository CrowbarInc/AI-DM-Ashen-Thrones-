# 12 — Architecture C Specification

C builds candidates only from referent structure: replace each existing role, reverse speaker and recipient when both exist, replace predicate or qualifier, and the closed follow-up kinds, plus `new` and `clarify`. The utterance is not read by the generator. The model must return one supplied id. Unknown ids are rejected with no nearest-id repair.

Exact candidate kind matched the label on 94 of 126 non-open cases. Full selection success, which also requires the resulting meaning, is 57/126. Missing-candidate count is 0 because the generator already offered a broad set, including `new`. That means this run did not show C forbidding an available meaning; it showed selection errors. Six cases were labeled `open` because debtor/creditor or multi-field swaps are not speaker/recipient reversal.
