# 27 — Source and Evidence Inventory

source_inventory.json lists cycle source hashes and predecessor-match checks. historical_preservation.json checks original failure evidence against the archived predecessor bundle. baseline.json records revision, initial dirty status and safe configuration. original_reproduction.json / repaired_reproduction.json show the divergence before and equality after repair. live_turns.json contains complete response/contracts, before/after state, canonical differences, provider usage, emitted text and history. Fresh and controlled evidence are separate. JUnit and exact regression comparison preserve pass/fail identities. Failed-first-live artifacts explain the discovered legacy gap. CURRENT_REVIEW manifest lists every packaged file with SHA256; no credentials, dependency trees, caches or other handoffs are bundled.
