# Repair the critical final-response integrity defect

#
# THE RESPONSE DELIVERED TO THE PLAYER MUST BE THE
# RESPONSE AUTHORIZED BY THE FINAL DELIVERY GATE.
#
# No downstream operation may replace, rewrite,
# embellish, or substitute the authorized response
# without passing through a new complete authorization
# and validation decision.
#
# The same invariant must apply to:
#
# - Player-facing API output.
# - Delivered conversational history.
# - NPC speech commitments.
# - Persisted dialogue records.
# - Save/load continuation.
# - Any downstream response consumers.
#
# This is an integrity repair, not a conversational
# quality improvement campaign.
#
# Do not attempt to make PR-EG conversationally
# playable within this cycle.

# ============================================================
#

#    substitution.

#    replaced by another unvalidated response.

# C. The final delivery gate must own the exact
#    response authorized for delivery.
#
# D. Delivered history must record the exact
#    authorized response.
#
# E. Speaker and addressee authority must remain
#    consistent.
#
# F. No new world-state authority may be granted
#    to narration or expression providers.
#
# G. Existing legitimate authorized dialogue must
#    remain functional.

# H. Information-integrity protections from
#    PR-EG-R2C and PR-EG-R3 must remain intact.
