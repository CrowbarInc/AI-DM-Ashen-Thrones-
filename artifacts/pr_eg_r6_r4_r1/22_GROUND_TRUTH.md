# 22 — Ground Truth

Pre-provider labels specify expected answer class, exact allowed answer values, mandatory qualifiers, forbidden content, question diagnostic representation and source-supported claim/role annotations. Host source records define provenance, NPC membership, context and disclosure. Supported-claim annotations are sparse and not exhaustive. Labels come from the author independently of model responses; they are not independently human reviewed. Runtime adapters never read labels to decide candidate answers. Exact content, required phrases and class determine frozen scores; forbidden values are rejected through allowed-value set comparison for positive answers. Reasons and missing-argument prose are ungraded, so do not treat all generated text as verified.
