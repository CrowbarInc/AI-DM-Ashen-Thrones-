# 12 — Validation Trust Levels

STRUCTURALLY_VALID: schema and source access passed (B). SOURCE_ANCHORED: C literal/metadata constraints passed. SEMANTICALLY_SUPPORTED: requires a trusted entailment procedure or bounded proof; not reached here. HUMAN_REVIEWED: requires an actual reviewer record; none exists. REJECTED: mechanical check failed. Human review does not itself change canonical authority. All extracted facts remain proposals; all candidate outputs carry delivery_authorized=false and canonical=false.
