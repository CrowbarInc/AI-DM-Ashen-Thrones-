# 06 — Architecture Specifications

A: current production system prompt and proposal schema, source prose interpreted per question, unchanged correspondence kernel. B: one provider extraction per family, structure/source-availability checks, immutable cached facts; one raw-question alignment per question. C: same extraction and alignment contracts, plus mechanical span/argument/scope/authority/identity validation before facts reach alignment. Separate B/C extractions introduce stochastic differences, so C-versus-B is not a pure paired-validator ablation. Both apply a post-alignment candidate anchor gate.

No arm delivers a response or grants world authority. A/B/C differ in output representation capacity; the single-proposition A contract can lose conjunctions. Report contract effects rather than claiming a universal algorithmic improvement. CONTRACT.md is the full preregistered protocol.
