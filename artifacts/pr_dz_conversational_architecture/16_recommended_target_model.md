# Recommended Target Model

Conceptual player-turn lifecycle:

1. Understand the player: communication mode, intent family, primary goal, incidental context, missing slots, implied addressee/topic.
2. Determine whether a world operation is required.
3. Resolve missing information when safe: active interlocutor, current inspected item, current scene, recent claim.
4. Validate proposed operations through existing authority gates.
5. Execute authoritative changes only through existing resolvers.
6. Persist consequential results as today.
7. Respond naturally: answer, clarify, decline, narrate result, or acknowledge correction.
8. Preserve relevant context: active interlocutor, topic, unresolved intention, recent facts, failed attempts.

Keep unchanged: exploration/social/combat/adjudication resolvers, storage ownership, CTIR/narration-plan authority seams, final-emission validation, and bounded improvisation constraints.

Change: replace direct interpretation-to-action bridge as the first production gate; add non-mutating conversational outcomes; add primary-intent/incidental-context representation; add slot-specific clarification.

Retire or reduce: generic "clearer action or target", generic "Which single action" for primary-intent turns, and phrase-table start handling as the only chat start route.

LLM discretion: interpret intent and generate natural response once authority decision is known. Engine authority: binding, mutation, persistence, consequential fact commitment, legality, and validation.
