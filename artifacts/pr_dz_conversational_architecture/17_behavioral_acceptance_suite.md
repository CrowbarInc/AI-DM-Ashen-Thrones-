# Behavioral Acceptance Suite

1. Start a new campaign: lifecycle start; opening scene resolution; no arbitrary state changes.
2. Ask contextual question: answer/hedge from established facts; no invented lore.
3. Continue NPC dialogue: use active target/topic; no target prompt unless ambiguous.
4. Ask unmarked OOC question: no state change; concise rules/help answer.
5. Leave NPC conversation: loosen social focus; no forced multi-action question.
6. Incomplete movement: ask destination-specific clarification; no scene transition.
7. Valid inspection: discover/repeat authorized clue only through resolver.
8. Repeat prior inspection: acknowledge prior check and summarize existing information; no duplicate discovery mutation.
9. Creative plausible action: propose operation or clarify; execute only if authority validates.
10. Impossible action: decline or explain obstruction; no mutation.
11. Ask about earlier narration detail: bind to recent memory; answer, hedge, or clarify.
12. Resume saved conversation: preserve active scene/interlocutor/topic where valid; do not replay opening unless lifecycle says so.

Acceptance criteria should be behavioral, not exact wording. For every scenario record intended interpretation, execution-needed flag, clarification-needed flag, permitted state changes, prohibited state changes, and acceptable player-facing response.
