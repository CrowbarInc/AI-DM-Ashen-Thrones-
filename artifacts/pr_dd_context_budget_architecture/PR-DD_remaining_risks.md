# PR-DD Remaining Risks

## Unresolved authority

`scene.gm_only.hidden_facts` is inside every authored frontier-gate provider request measured here, including harmless preference and the secret-tunnel question. The four secrets occur only at that path. The list is 372 bytes. The layering rule tells the model to use them for implications, and a separate instruction says not to reveal them. Removing the list would slightly cut tokens and would remove a spoiler channel. Whether implication quality depends on the list was not tested. Cycle 1 does not touch it.

`gm_resolution_decision` and `decision_facing_answer_recipe` overlap and have different roles. Compacting them before a projection test can create a second authority story. That work is cycle 4 and stays inside the existing harmless predicate.

## Measurement gaps

`tiktoken` is not installed. Every token figure from this audit except the historical PR-CY and PR-DA tables is `ceil(chars/4)`.

Hashes are `build_messages` hashes with `ensure_ascii=False`. The API can rewrite the user message with `ensure_ascii=True` and attach `response_type_contract` after that call. Live HTTP bytes can differ.

S1 preference and C1 consequential hashes match PR-DC exactly. S2 and S3 match PR-DC's byte counts and projection decision, and their hashes do not match PR-DC. The differing bytes were not isolated. Multi-turn baselines must record the PR-DD hash until a cycle explains the drift.

Combat and skill-check shapes come from existing synthetic tests. Authored scenes have no enemies and no skill-check configuration. An authored search did not roll. Campaign budgets for those classes are not evidenced.

"I walk closer to the notice board." did not bind an exit. "Describe what I can see around me here at the gate." resolved as unresolved generation. Those two lines are limitations, not clean examples of movement and observation.

## Product risks if the sequence is collapsed

Deleting reinforcement instructions in the same change as the exact dedupe would make a quality regression impossible to attribute. PR-BT already had to restore an epistemic sentence.

Widening the harmless projector to save the opening block on consequential or authored-fact turns would trade the 11% safe saving for an authority hole the current predicates exist to prevent.

Chasing a single token cap by switching exploration and transitions to the narration-only system prompt would shrink about 5.4 KB of instructions and would drop the structured claim envelope those classes measured as active.
