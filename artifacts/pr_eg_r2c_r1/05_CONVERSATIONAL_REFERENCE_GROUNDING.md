# 05 — Conversational Reference Grounding

Reference grounding removes speech-act/control terms and speaker names from current subject evidence. A named speaker restricts the candidate pool; it cannot silently fall back to someone else. Explicit subject selects relevant delivered statements ahead of recency. A deictic repeat without a subject chooses the latest statement of the grounded speaker. Equally plausible different statements/speakers clarify. A missing historical referent clarifies rather than fabricating dialogue. New factual deictic questions still go through the social resolver.

Exact and simpler repetition reuse original delivered text, including long statements and uncertainty qualifiers. No paraphrase provider call is needed. Meaning/repetition requests do not reveal an unrelated authored topic or create a new clue. T01–T08, T13–T14 and the two recall-bypass regression controls inspect selected records, not only output substrings.
