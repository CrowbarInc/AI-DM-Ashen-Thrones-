# 07 HOST OPERATION AUTHORITY

Uncertainty, clarification, refusal, and acknowledgment are `host_operation` when they do not carry a protected or consequential addition. The check is [game/dialogue_authority.py:192](../../game/dialogue_authority.py#L192) and [game/dialogue_authority.py:220](../../game/dialogue_authority.py#L220). A refusal that also states a protected fact is rejected. A host operation does not create a discovered clue.
