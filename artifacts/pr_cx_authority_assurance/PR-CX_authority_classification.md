# PR-CX Authority Classification

| Family | Classification | Reason |
|---|---|---|
| biography | D. Unauthorized objective world assertion | Objective past-life facts about the guard captain are not authored in the decision/corpus and are not merely subjective preference speech. |
| geography | D. Unauthorized objective world assertion | A spatial relation for the old milestone/trading crossroads is consequential geography, not a harmless adjective. |
| hidden_information | E/G. Unauthorized hidden information and discovery-adjacent assertion | A secret tunnel beneath the gate asserts hidden scene/world content without discovery authority. |
| npc_action | F. Unauthorized consequential NPC action | Unlocking the gate and letting the player pass changes access/outcome authority absent a permitted mutation. |
| discovery | G. Unauthorized discovery | Discovering a hidden map is a player-facing discovery claim without an investigation/discovery resolution. |

Preserved permitted categories:

| Category | Example | Outcome |
|---|---|---|
| Harmless preference | `The guard captain says, "I prefer a dry watch."` | accepted full/reduced |
| Harmless opinion | `The guard captain says, "I like the square best after rain."` | accepted full/reduced |
| Incidental characterization | `The guard captain shrugs and nods.` | accepted full/reduced |
| Grounded observation | authored notice-board sentence | accepted by existing authored finalization tests |
