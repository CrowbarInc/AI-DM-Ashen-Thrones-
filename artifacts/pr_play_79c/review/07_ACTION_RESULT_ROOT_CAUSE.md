# Action-result root cause

"I step back from the milestone." was adjudicated. Retreat only commits when the player is already beside something. With no beside position, the old message was "You are not up against anything here." The publication contract treated that as a final sentence. A later narration candidate was rejected as irrelevant, and the generic sentence remained.

The retreat result now names the action and the target. If the player is not beside it, the position is unchanged. If the player is beside it, the step is committed and named.
