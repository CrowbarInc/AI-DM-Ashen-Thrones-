# 15 — Information Integrity Containment

INFERENCE: recommend a separate repair before R3. At social speech adoption, admit only host-owned outputs derived from actual resolver-selected disclosable topic/outcome, an existing bounded_personal_line when the dialogue owner allows personal characterization, or a knowledge-appropriate nonbinding refusal/uncertainty. Existing authored fact realization preserves legitimate operational facts, as supplemental E demonstrates. It must never apply an unconditional high-risk-word ban. The selected authored topic must itself have provenance/disclosure checked; arbitrary generated text in a topic-shaped object is not enough.

Candidate A (do not adopt unsupported generated claims): credible only if support is closed by construction. A semantic PASS alone fails here. B (restrict high-risk narration): insufficient if routing/classification must recognize all risk first. C (evidence for promises): useful but does not contain security/causal leaks. D (unresolved response): useful when driven by resolver posture, but not every answer should become refusal. E (separate incidental from consequential): design distinction is necessary, yet prose separation is not demonstrated reliable.

Smallest credible independent repair is therefore a bounded host-owned social delivery lane, coupled to final adoption identity and noncanonical-history safeguards. It temporarily restricts open incidental elaboration; it still answers selected facts, states simple preferences and gives appropriate refusals. No new provider call or semantic classifier is necessary. Existing reply catalogs should not expand into an unbounded replacement knowledge system. Legacy delivered speech may be quoted as what was said, but cannot acquire factual authority or be reused as fresh authorized NPC assertion without evidence.

This is not implemented or qualified. Open-ended natural incidental speech cannot be safely retained by the tested validator alone. If maintaining that feature is mandatory during containment, no narrow repair has been demonstrated. Test all social entry/early-return paths and downstream transforms before claiming containment.
