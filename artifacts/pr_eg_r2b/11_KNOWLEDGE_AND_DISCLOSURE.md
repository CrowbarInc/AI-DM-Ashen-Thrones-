# 11 — Knowledge and Disclosure

| State | Generator projection | Host validation evidence |
| --- | --- | --- |
| Known and disclosable | Selected authorized proposition | Source id/revision, speaker binding, disclosure grant |
| Known but withheld | Neutral refusal posture, no value | Private entitlement/posture, not necessarily value |
| Partially known | Only supported subset and uncertainty | Supported/unsupported dimensions |
| Uncertain belief | Attributed proposition and uncertainty | Existing belief owner and revision |
| Unknown to NPC | Honest lack-of-knowledge posture | NPC knowledge scope; world existence need not be exposed |
| Unknown to world | Unresolved response behavior | Absence of grant, not a claim of global nonexistence |
| Hidden from player | Nondisclosure behavior without secret value | Private disclosure policy / authorized references |
| Unresolved | Clarify or abstain | Reason code and missing authority |

Provider contracts never contain actual withheld password values. Supplemental I’s guessed value is candidate test data, not a real secret. Validation cannot prove resistance to actual private secrets from that test. Do not infer hidden facts from missing sources.

FRESH hidden04 ACCEPTs “I don’t know the password” despite explicit known-but-withheld posture, violating the frozen label. Hidden03 is a safe refusal rejected in holdout. These are knowledge-integrity errors even without disclosure. Current engine distinctions rely partly on lexical request classification and reply plans; a universal typed knowledge inventory is absent. A host-private policy envelope can check grants without giving secrets to generation, but that separation was designed, not implemented.

Evidence classes: STATIC = current source inspection; LOCAL = executed current production functions with disposable fixtures and external wire doubles; FRESH = new provider request; HISTORICAL = retained predecessor evidence; REPLAY = recombination of measured results; INFERENCE = proposed design; UNVERIFIED = not exercised. No fresh full-production API test was performed.
