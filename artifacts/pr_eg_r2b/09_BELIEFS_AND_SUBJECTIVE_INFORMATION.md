# 09 — Beliefs and Subjective Information

| Category | Required authority / response |
| --- | --- |
| Established belief | Source-owned NPC belief, disclosure authorization, preserved attribution and uncertainty; never objective upgrade |
| Harmless spontaneous opinion | Existing incidental allowance; nonbinding and not about consequential hidden/operational claims |
| Uncertain recollection | Established content and uncertainty state; missing memory is not permission to invent a recollection |
| Rumor | Explicit authored rumor and permission to disclose, with source/epistemic limits; arbitrary attribution cannot grant it |
| Deliberate deception | Existing resolver/narrative grant for that specific deception; otherwise abstain or decline |
| Withheld knowledge | Preserve withholding without transmitting the value or inventing ignorance |

A false belief still influences choices, so falsehood does not make an unsupported security allegation harmless. The frozen belief context authorizes Mara’s belief about the captain while leaving objective truth unsettled; explicit belief attribution is required. Current topic selection often carries plain text, so a general belief/deception schema is a missing capability, not an implementation assignment. Do not infer new belief state from a generated utterance or noncanonical memory. No deception system was added.

Evidence classes: STATIC = current source inspection; LOCAL = executed current production functions with disposable fixtures and external wire doubles; FRESH = new provider request; HISTORICAL = retained predecessor evidence; REPLAY = recombination of measured results; INFERENCE = proposed design; UNVERIFIED = not exercised. No fresh full-production API test was performed.
