# 07 — Answer-Class Definitions

DIRECT: all requested arguments supplied by authorized evidence with matching roles/qualifiers. PARTIAL: only part of the request supplied, an unidentified participant, qualified candidate, or unresolved contradictory answers. RELATED_NONANSWER: same subject but wrong relationship, direction or qualifier. UNKNOWN: no eligible supporting evidence. CLARIFICATION_REQUIRED: genuine ambiguity in the question. RESTRICTED: relevant host-known evidence exists but is denied.

Keep relevance, sufficiency and disclosure separate. Rumor and conflict candidate bindings are not canonical truth. The six classes require an explicit conflict/uncertainty policy; this corpus uses PARTIAL for disagreement and qualified candidates. Changing that policy would require a new corpus version, not editing these frozen labels.
