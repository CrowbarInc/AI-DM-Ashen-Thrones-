# 21 — Negation and Qualifiers

Core cases cover positive versus negative claims, yesterday versus today and rumor versus unqualified knowledge. Supplemental probes add matching and mismatching space, possibility, conditionals, approximation, explicit uncertainty and an affirmative answer to a negative question. Host output retains the source epistemic/temporal/spatial/polarity fields and original authorized text.

Conditional and approximate epistemic labels are experimental strings, not a proposed production schema. For these cases the independently authored class is PARTIAL. A production design needs explicit conditional scope and numeric uncertainty, rather than stuffing them into a single epistemic string. Qualifier correctness on safe UNKNOWN is vacuous; inspect extraction and answer success too.
