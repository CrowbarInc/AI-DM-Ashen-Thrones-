# 27 — Failure Attribution

{
  "A": {
    "E03": 10
  },
  "B": {
    "E02": 8
  },
  "C": {
    "E03": 89,
    "E14": 26
  }
}

C commonly returned requested_role still populated while also supplying that role in roles. This is a malformed source interpretation (E03), not evidence that host authorization should be loosened. Other C failures are exact semantic-signature rejection (E14), including articles/value normalization and missing manual annotations. A often omitted content from tell sources; structurally well-formed output still lost the answer. B loses all prose-only facts at representation/retrieval (E02).

Attribution is deterministic triage followed by raw examples, not an independent blinded human panel. Exact semantic source errors can have multiple causes; external review should inspect raw JSON before accepting a general architecture conclusion.
