# 22 — Conflicting Evidence

Eight core cases provide two public, NPC-known sources naming different keepers. Shared aggregation retains both candidates, marks conflict=true and returns PARTIAL. Neither is selected as canonical truth. Production native selection instead treats multiple direct sources as proposition ambiguity; this difference is explicit in the A adapter specification.

No source priority, time-based reconciliation, majority vote or silent winner is implemented. Provenance-specific conflict policy and contradictory epistemic status remain future design questions.
