# 05 UNIVERSAL DISCLOSURE CONTRACT

The common deterministic contract lives inside existing dialogue authority: [game/dialogue_authority.py:111](../../game/dialogue_authority.py#L111). It resolves speaker, addressee, exact source text/identity, classification, knowledge, permission, epistemics, operation, authorized proposition/clue text, provenance and validation. Existing outer dialogue authority, expression contract and accepted-response record continue to carry proposition identity and authorized speech. There is no second persistent authority store. Provider source IDs alone never authorize a source. Production final adoption supplies the host world and re-resolves the source; pure callers without world must carry a matching host receipt.

Limit: a receipt is an internal projection, not a cryptographic capability; do not expose a caller-controlled receipt as an API authority input.
