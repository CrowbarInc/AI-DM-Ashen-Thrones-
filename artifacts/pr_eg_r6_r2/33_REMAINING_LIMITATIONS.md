# 33 Remaining Limitations

One-pass role/source interpretation is unreliable on corrections and ellipsis. Exact reference binding is brittle. Literal argument identity rejects genuine argument paraphrases with no canonical alias. Source predicate entailment still depends on provider interpretation, with exact witnesses providing bounds rather than a semantic proof. Candidate caps can omit relevant facts. Partial and unknown handling differ from inherited expectations. New holdouts and local scores lack external human independence. State/discovery scans are bounded, not exhaustive.
