# 08 — NPC Knowledge and Uncertainty

| Situation | Posture | Spoken behavior in this cycle |
| --- | --- | --- |
| Topic supports the request and is not hedged | established | Authored realization. Provider narration still runs once. |
| Topic supports the request and is hedged | partial | The topic text. Narration is not skipped. |
| Personal state or opinion, not a refusal | belief | Improvisation permitted. One narration unless a safe quote is recovered from a rejected draft. |
| Hidden request | withheld | “I couldn’t answer that.” No narration. |
| Promise, mystery, relationship, rumor, unanswered surveillance or ownership | unestablished | “I couldn’t tell you.” No narration. |
| Maker or other listed kind with no topic | unknown | “I couldn’t tell you.” No narration. |
| General question with no topic | unknown | Not narration-determined. The existing provider path remains, including speaker repair. |

These are not the same state. A missing world fact does not by itself forbid speech, and it does not permit an invented fact. Personal questions may be answered as belief. Surveillance, maker, and hidden questions may not be invented.

The determined lines are two sentences, not a catalog of phrasings. Hostile or restricted plans still hit `genuine_refusal` before the personal-question branch in the reply-plan function.

A refusal is the withheld line. It does not explain the engine rule. When generation fails for a turn that already has a dialogue-authority record, the fallback is that same in-character line rather than “from what is settled here.” If that line itself fails validation, the terminal text is still “I cannot provide a validated response to that request.”

Live evidence: the lantern question and the password question used the determined lines and did not narrate. The preference question was allowed to narrate and came back as ignorance rather than a preference. The eye-on-the-road follow-up never reached this table.
