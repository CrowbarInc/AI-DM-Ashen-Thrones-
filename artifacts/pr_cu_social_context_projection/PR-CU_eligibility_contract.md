# PR-CU Eligibility Contract

Status: draft only; not implemented.

A reduced harmless-social projection would require all of these to be authoritatively known from existing deterministic fields:

1. Resolver identifies an ordinary social exchange.
2. Requested answer is harmless and subjective.
3. Addressee is unambiguous.
4. No consequential adjudication is required.
5. No hidden fact must be revealed.
6. No restricted NPC knowledge is requested.
7. No world-state mutation is requested.
8. No physical action is requested.
9. No combat action is requested.
10. No unresolved authored-topic obligation exists.
11. Required scene/NPC continuity remains available.
12. Existing authority and output contracts remain fully enforceable.

Gate outcome:

This contract was not implemented because Phase 1 showed existing provider-facing authority/output policy contracts are not fully enforceable for the ordinary NPC dialogue probe.
