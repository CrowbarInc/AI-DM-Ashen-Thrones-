# PR-CZ Follow-Up Eligibility Contract

Eligible:
- The immediately preceding discourse focus names one active interlocutor.
- The current turn is an ask or short elliptical follow-up.
- There is no explicit new addressee.
- There is no scene mismatch.
- The inherited interlocutor remains the existing authoritative discourse target.

Ineligible:
- Explicit switch to another addressee.
- Scene transition or scene mismatch.
- Ambiguous addressee.
- Non-social action.
- Missing authoritative discourse focus.

Uncertain cases stay on the conservative path.
