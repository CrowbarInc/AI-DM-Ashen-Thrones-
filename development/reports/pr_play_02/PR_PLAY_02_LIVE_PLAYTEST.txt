4. SHORT NATURAL SEQUENCE — ONLY WHILE THE SESSION CAN CONTINUE
Read the actual scene. Use people and objects it establishes, not hidden notes.
Opening already consumes budget. A turn can need interpretation plus narration
or expression; some turns need no narration. Complete only what fits:

A. NPC conversation: address a present NPC. Example: "I ask the tavern runner
   what news people are talking about."
B. Information: ask about a detail actually introduced: "What does that notice
   say about the missing patrol?" Adapt to the delivered scene/reply.
C. Follow-up/correction: ask about a named detail, or correct an actual misread:
   "I meant the people, not the weather." Do not manufacture a mistake.
D. Ordinary noncombat action: inspect something visible, e.g. "I examine the
   notice board." Do not assume it succeeded if the game blocked it.
E. Continuity: refer to an event that actually occurred, e.g. "What did I just
   learn from the board?" Skip if that inspection never completed.

Use the ordinary input box and Send. Never resend while waiting. Keep one input
in flight. The interface may say "The controlled playtest request limit has
been reached". STOP immediately, including if the planned sequence is unfinished.
The sixth admitted operation may finish normally. Subsequent operations cannot
dispatch. An action resolved before a narration refusal remains resolved; check
state and record the result, without treating absent narration as a new action.
Pending confirmations, OOC text and Start Campaign are also stopped once capped.
