# NESTED DATA PROTECTION

Explicit schemas protect inventory items, attacks/damage, hit points, spells/slots, NPC roster, interaction context, affordances, known clues, journal leads/effects, save slots and response envelopes. No arbitrary dictionaries/lists are accepted as a leaf. Hidden values under innocuous future keys, inventory descriptions, lead private notes, optional metadata and object-valued public-looking scalars are excluded.

Sentinel cases inspect complete JSON, not narration alone. The original five fields, undiscovered catalog and event triggers, private motives/objectives, provider prompts, validation traces and state diffs do not cross the boundary. Safe narration remains the output of the preexisting publication/validation owners: the DTO is not a semantic validator for arbitrary text in a legitimately authorized scalar.
