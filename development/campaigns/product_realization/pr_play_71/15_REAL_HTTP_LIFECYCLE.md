# REAL HTTP LIFECYCLE

Separate TCP lifecycle used ordinary HTTP creation/start/gameplay/snapshot routes in isolated storage, with offline opening provider fixture. 27 requests; 17 action/chat submissions. Both branches finish, save, restore, reject repeat/opposite effects, continue and switch snapshots. Complete JSON bodies and raw authority before/after are in http_traces.json. The initial pre-recovery run is retained separately. Final HTTP replay after persistence repair is distinguished from the earlier live-browser run.

Mean HTTP response 1857.6 ms; maximum 4956.7 ms. These are not browser latency. No direct internal resolver calls, session injection, manual discoveries or branch prepopulation were used by the lifecycle driver.
