# Subsystem Closure

This is an assessment of the bounded marking lifecycle. It is not a claim that object interaction is finished.

| Capability | Implemented | Verified | Limited | Missing |
|---|---|---|---|---|
| Persistent object identity | yes | yes | identity is the existing inventory instance | no general object database |
| Authoritative marking creation | yes | yes | needs an established surface, medium, and disclosed text | environmental media are not inferred |
| Marking visibility | yes | yes | classification is an established record | no player classification command |
| Marking observation | yes | yes | ordinary look shows current visible text only | it does not certify concealed absence |
| Marking removal | yes | yes | one visible marking, one established method | no bulk removal and no consumption writer |
| Natural-language creation | yes | yes | recognized copy/write language only | original T06 stays unresolved without prerequisites |
| Natural-language observation | yes | yes | one named accessible surface | a pronoun does not select |
| Natural-language removal | yes | yes | wipe, rub, erase, clean, remove, wash aimed at a marking word | general cleaning and destruction stay outside |
| Save/reload | yes | yes | the character writer and a new process | not a multi-process crash suite |
| Snapshot restoration | yes | yes | S0, S1, and S2 on the controlled garment | not every object timeline |
| Idempotency | yes | yes | request id plus stored removal digest | the in-memory lane still returns the first HTTP body |
| Publication consistency | yes | yes | committed sentence or a compatible paraphrase | not a general narration rewrite |
| Ruleset portability | yes | yes | pf1e, rules-light, and science-fiction fields preserved | required mechanics stay unresolved |
| Provider efficiency | yes | yes | local recognition and one existing seal | no live-model measurement |

Engineering completeness for this class is sufficient. Gameplay usefulness is the controlled case: a player can put a known warning on an established sleeve with an established removable medium, read it, wipe it off, read its absence, and see the same absence after reload. The original twelve-turn campaign still has no such garment or medium, so T06 correctly remains unresolved.

**Closure recommendation:** close the marking workstream as a bounded subsystem. Do not add another specialized marking feature as the next cycle. Remaining object interaction, conversation, and unsupported actions belong to a broader gameplay evaluation.
