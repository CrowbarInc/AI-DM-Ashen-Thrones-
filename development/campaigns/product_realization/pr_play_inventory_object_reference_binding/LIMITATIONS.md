# Scope and remaining limitations

General item descriptions, condition, color, material, pockets, contents, wearing/equipment and accessibility have no public descriptive authority here. They stay unknown. Only the existing markings category can provide authorized property content. No arbitrary private raw description is surfaced.

Matching is lexical and bounded. No semantic “book”→Spellbook alias is invented; unbound references now clarify. Singular/plural support is finite trailing-s inflection, not a language-wide inflector. Context is immediate-log inventory context only; it deliberately expires on unrelated delivered turns and scene/character changes. Legacy items without stable instances cannot distinguish a same-ID replacement beyond the existing contracts; duplicate names/IDs fail closed.

Provider-disabled ordinary HTTP is tested. Live-language fluency, provider interpretation and externally pre-stored interpretation routing are not certified. No live calls were made. Existing unrelated failures remain visible. Unsupported pocket search retains the inherited investigation tick and does not gain manipulation success. Physical actions, container searches and equipment changes remain outside this milestone.

Seven timing samples per family under concurrent regression load are descriptive, not statistically meaningful speedup evidence. State-change sequences use controlled authoritative setup because no new inventory mutation mechanic is permitted.
