# Limitations

## Evaluation

The twenty cases are a designed sample, not a random draw from play, and not a rescoring of the historical forty or fifty-five. Several expected admissions are conditional: a paraphrase of a supported action can be withheld without becoming an execution success. Speech turns accept a turn delta of 0 or 1 because the current contract does not fix a single advancement for every grounded question.

Sequence D travel uses a generic "track" wording. The destination binder treats track as generic and does not treat northwest alone as the authored exit. Withholding that paraphrase is PARTIAL, not a demand that an unsupported parse succeed.

## Provider

`gpt-4.1-mini` is deprecated on the official model page. TCP reachability to port 443 is not authentication and not proof the model is served. Cached-token discounts are unpublished in the application ledger, so the budget ignores them. SDK retries would hide inside one application request unless the playtest flag forces `max_retries` to 0. The production USD ceiling does not exist; only this harness reserves dollars. Interpretation uses a literal model id, while narration uses environment configuration. They match today and the gate refuses if they do not.

Measured turns that the deterministic owners already handle never reached `call_gpt`. A live run can therefore spend fewer than two calls on some cases and two or more on others. The 40-call ceiling can stop the sample early. That stop is a budget result, not a model score.

## Capability

The social-check entrance is the explicit verb pattern. "I keep my argument to myself." is scored as a required non-action, not as a successful persuade. The rain barrel is visible prose, not an interactable. Teleport is unsupported. Hidden watcher facts and canary strings are prohibited in narration. Spell text beyond the four prepared names is not established.

## Unknowns

Live interpretation quality, narration faithfulness, latency, retries, and the invoice are unknown. Billed cost can differ if the provider applies a charge that is not on the retrieved text-token card. Full-repository test cleanliness is not claimed.
