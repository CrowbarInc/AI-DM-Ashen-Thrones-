# Limitations and deferred defects

No live provider calls, live-model validation, remote outage test, independent held-out generalization, full-suite run, or Ashen Thrones Gameplay Benchmark. Scripted provider records test host safety, not model competence.

There is no generic conditional truth evaluator. Conditions remain withheld even when a matching true flag exists unless an already supported owner admits the whole request. This milestone adds no conditional executor. Mixed uncertain information (A4) and B1 interpretation eligibility retain their prior boundary. Conditional linguistic coverage remains finite and is not a proof for arbitrary English.

The guard protects the ordinary chat parsed-inspection route after existing deterministic/validated owners have first refusal. It is not a new global transaction framework and does not establish atomicity for all structured endpoints, optional experimental owners, combat or unrelated subsystems. Raw exploration resolution still has a permissive unsupported-result success shape; ordinary HTTP now prevents such a target reaching that resolver. Broadly changing legacy resolver contracts is deferred.

J01 mixed-request omission, C03 pronoun scope, E01/F03 interception and missing authored spellbook contents remain deferred. Social repeat/legacy stance remains PAUSED. Inherited regression failures are retained verbatim. Conversational context, last-publication bookkeeping and save timestamps may change; authoritative scene/character/world/combat state and action time must not.
