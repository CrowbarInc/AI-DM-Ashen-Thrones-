# Limitations and open risks

1. Visible authored choices are not reachable by saying their labels. The report branch required the suggested-action button. This is the dominant playability bottleneck.
2. After those grounded ideas are used, nothing new is offered. The extended session spent 14 of 34 turns repeating one look-around. The objective was not completed in that session.
3. A mixed examine-and-ask does not run authored discovery. The clue requires a dedicated examine.
4. "Who are you?" clarifies whenever more than one person is present.
5. A conditional sentence at the milestone published the gate opening without moving the scene. Cause not isolated. No hidden fact was added. The publication still contradicts the place.
6. Bounded speech can accept ordinary-sounding conditions that the host did not commit. The pre-fix "mud track gets tricky" line is the example. Scene scoping stops the wrong NPC. It does not define that class of sentence.
7. Narration and speech-adopted flags on the session stick, so a later turn can look accepted when it did not call the provider. Counts in this package do not use the sticky flag.
8. Climbing and carrying remain unsupported. No check is invented.
9. The holdout repeats templates for narration, dialogue, readonly, and publication. It is developer-authored.
10. HTTP campaign sentences were not written to a trace file. The passing assertions are the HTTP evidence.
11. Browser play did not use the live provider. Live narration and dialogue were shown on the gate script and, with the scene bug, on the extended script.
12. The first extended chooser looped on climb. The scored transcript is the second chooser. Both are adaptive scripts, not a human.
13. Snapshot ids from campaign A remained listed during campaign B because both campaigns shared one browser data directory.
14. Working tree still contains uncommitted PR-PLAY-55 through 77 work. This cycle did not commit it.
