# Validation Cleanup & Governance Repair

## Executive Summary

This campaign repaired all 17 authorized validation-estate failures and preserved all six frozen
policy/unresolved failures. The full suite moved from 23 failures to 6. No test was skipped,
xfail-marked, deleted, or weakened for appearance. Production gameplay semantics and validation
authority classifications did not change.

## Starting Baseline

`PRE_CLEANUP_BASELINE`: 6,445 collected, 6,323 passed, 23 failed, 99 skipped. The failing set
matched the post-Confirmed-Baseline-Repair handoff exactly.

## Frozen Cases

- RC-10: local raw-token boundary policy, one failure.
- RC-21: destination redirect lead authority, three failures.
- RC-11: opening accepted-candidate sequence, one unresolved failure.
- RC-13: long-session direct-intrusion lineage threshold, one unresolved failure.

These tests remain red and were not modified, skipped, xfailed, or reclassified.

test exemption.
